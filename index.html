1. Load a CSV export

Have recorded cleanups already?

Export your master spreadsheet to CSV and load it here. The map, charts and event log will update together.

This CSV import runs in your browser. Nothing you upload here is sent to the dashboard developer. Refreshing the page restores the embedded real-data snapshot. Public Google Sheets reads are requested directly from Google.

2. Connect a Google Sheet (experimental)

Use a public/read-only Sheet with the cleanup columns. A linked Google Form can add new responses to that Sheet.

Select the correct tab in your Sheet URL (the original source uses Sheet1; an explicit gid=0 works). The public Google Visualization data endpoint is used for this demonstration; publishing permissions and network access are required. On successful connection, updates are checked every two minutes while this page stays open. This is not private authenticated access.
Source: Actual Data Coral Cartel. If the source is private, use CSV export instead; do not change its sharing permissions just to test this. Only publish a sanitized copy if Coral Cartel approves public access.

3. Add a cleanup (browser-only prototype)

Test the full data-entry → dashboard flow here. This does not write to the original Google Sheet. Export all records to CSV afterward to keep your edits.

Prototype only. Changes are lost when you reload unless you export CSV. Actual Form → Sheet automation is for David to configure and secure.

4. Suggested Form → Sheet process

  1. Create a Google Form for each cleanup event, not each individual rubbish item.
  2. Use date, site name, coordinates and pounds by debris type as questions.
  3. Google Form → Responses → Link to Sheets.
  4. Create a tidy Cleanups tab matching the column names below; copy/transform Form responses if necessary.
  5. Load a CSV here or make a sanitized Sheet publicly readable for experimental connection.

5. Schema for the prototype

Minimum required: cleanup identifier/date/site/latitude/longitude. For realistic charts, enter material weights in pounds. Total_lb is optional; the website will add the material columns if it is blank.

Latitude and longitude must be decimal degrees, for example 19.2959 and -81.3848. Keep all weight columns numeric (without lb text).

Data source: Coral Cartel public read-only Google Sheets feed. New records are checked automatically when this page opens, approximately every two minutes while open, and when returning to the tab. Google Sheets import caching may introduce additional delay. Satellite imagery uses an external service; a GPS-only plot appears if the mapping library cannot load. Prototype only; review GPS privacy and data quality before public launch.
